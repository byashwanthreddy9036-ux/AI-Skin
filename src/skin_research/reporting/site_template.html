Research question

Does a better photo of a skin lesion make an AI classifier more accurate?

Educational research prototype. Not a medical device and not for diagnosis. Every number on this page comes from the experiment's own output files.

How it works

Same images, same model, only the image quality changes

Every condition uses exactly the same lesions and the same frozen model, so any change in accuracy comes from the image transformation. The steps run in this order.

By diagnosis

Which diagnoses break first

Sensitivity is the share of lesions of each diagnosis that the model identified correctly. Darker cells are higher. Columns with very few images (shown as n) swing between 0 and 1 easily.

    Limitations

      Run it yourself

      Commands

      Run from the project folder in a WSL or Linux terminal. Each command can also be written as python -m skin_research.cli <command> inside the virtual environment.

      Testing

      Checking that nothing is broken

      automated tests cover every module. Two of them use the real model and real images; they report skipped, never passed, when the data or weights are not downloaded.
